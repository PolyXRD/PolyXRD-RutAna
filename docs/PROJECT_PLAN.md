## 2. 标准要点冻结（GB/T 30793—2014）

### 2.1 A 法 · 强度比值法

| 项 | 条款内容 |
|---|---|
| 原理 | 测锐钛型与金红石型**最大衍射峰**强度，把锐钛型峰强换算成相对于金红石型的锐钛型含量，金红石型含量由差值确定 |
| 分析线 | 锐钛型 (101) ≈ 2θ 25.3°；金红石型 (110) ≈ 2θ 27.4°（Cu Kα） |
| 扫描范围 | 24.5° ≤ 2θ ≤ 26.5°（锐钛型）与 26.5° ≤ 2θ ≤ 28.5°（金红石型），**两个范围分别扫描** |
| 扫描速度 | 0.25°/min，或 0.02°/步、每步 4.8 s |
| 测试次数 | 每个样品两次平行测定；每个窗口扫描两次，**取两次净峰强度的平均值** |
| 峰强单位 | 标准注明「由于只采用比率，峰强度可以用任何适合的单位」 |
| 校准物质 | 100% 金红石型 + 100% 锐钛型颜料，按预定比例称量（**精确至 0.1 mg**），乙醇分散、混匀、干燥、玛瑙研磨、过 45 μm 筛 |
| K 值 | **K = (I_a/I_r)/(m_a/m_r)**，即强度比对质量比作图的**校准曲线斜率**（多点拟合，非单点） |
| 结果计算 | **w_a = 1/(1 + K·I_r/I_a) × 100%**；**w_r = 100 − w_a** |
| 干扰物 | 先做 5°–90° 快扫定性；附录 A 列硫酸钙、铬黄、锑华等；高含量 Fe 建议换 Co/Mo 靶 |
| 择优取向 | 定量前须与 PDF 卡片核对峰强比检查择优取向，存在则重新制样 |
| 仪器 | 综合稳定度优于 1%；0.1% 锐钛型信号至少 4 倍噪声 |

### 2.2 B 法 · Rietveld 全谱拟合法

| 项 | 条款内容 |
|---|---|
| 原理 | 基于晶体结构模型 + 峰形函数计算多晶衍射谱，调节结构/峰形参数使计算谱与实测谱符合，进而求比率 |
| 扫描范围 | 5° ≤ 2θ ≤ 90°；2°/min 或 0.02°/步、每步 0.6 s |
| 测试次数 | 每个样品两次平行测定 |
| 流程 | 快扫定性 → 确定扫描范围 → PDF 检索定相 → 建结构模型 → 标定衍射指数 → 计算并 Rietveld 精修 → 判定 Rwp |
| 结果计算 | **w_a = w_aR/(w_aR + w_rR) × 100%**；**w_r = 100 − w_a**（w_R 为各相 Rietveld 定量质量分数） |
| 合格判据 | **Rwp ≤ 10%** |

- [ ] T4　报告必须包含的字段清单（第 9 章 / 试验报告条款）
- [ ] T5　附录 A 干扰物完整清单与去除流程

### 2.4 原理边界（写进软件说明书，也写进报告模板）

1. 两法给出的都是**「相对于另一晶型的比率」**，分母是两晶相之和，**不含无定形包膜**（TiO₂ 颜料普遍有 Al/Si/Zr 包膜，通常 1–5%，不在结果里）。
2. 若样品含第三晶相且未建模，A 法结果会系统性偏倚，B 法会直接把未知峰算进背景/残差 → 软件必须做「额外相提示」。
3. 标准自己也承认干扰：**两晶型粒度差别过大**时结果不可靠（微吸收效应），须在 UI 与报告中警示。

**数据流**

- A 法：`*.xy` → 窗口裁剪 → 背景扣除 → (I_a, I_r, QA) → K → (w_a, w_r) → 判定 → 报告
- B 法：`*.xy` → 初值(A 法结果即可) → 前向计算 → 线性层解 (S_p, b_j) → 非线性层调 (zero, U,V,W, η) → 收敛 → R 因子 → QPA → (w_a, w_r) → 判定 → 报告

## 5. 关键公式（实现时逐条落单元测试）

**A 法**
```
K          = slope( I_a/I_r  vs  m_a/m_r )，多点最小二乘
             过原点：K = Σ x_i y_i / Σ x_i²
             通用：y = a·x + b，报告 a、b、R²，默认采用"过原点"口径
w_a        = 1/(1 + K·I_r/I_a) × 100%
w_r        = 100 − w_a
双平行      Δ = |w_a1 − w_a2|，与标准重复限比较（待 T1 确认数值）
不确定度     u_rel(w_a) ≈ (1 − w_a/100)·√[ (u(I_a/I_r)/(I_a/I_r))² + (u(K)/K)² ]
```

**B 法**
```
y_c(2θ_i) = Σ_p S_p · P_p(2θ_i) + B(2θ_i)
P_p       = Σ_hkl LP(θ)·|F_hkl|²·Ω(2θ − 2θ_hkl − zero)，Ω = pseudo-Voigt
             可选修正：March–Dollase W(α,r)、Kα1/Kα2 双线、尺寸/应变展宽
FWHM²     = U·tan²θ + V·tanθ + W            (Caglioti)
B(2θ)     = Σ_j b_j·T_j(x)，x ∈ [−1,1]      (Chebyshev，2–6 项)

Rwp  = 100·√[ Σ w_i (y_o−y_c)² / Σ w_i y_o² ]，w_i = 1/σ_i²（计数统计 σ_i² = y_o）
Rexp = √[ (N−P) / Σ w_i y_o² ]，  χ² = (Rwp/Rexp)²

定量（Hill–Howard）：W_p = S_p·Z_p·M_p·V_p / Σ_q S_q Z_q M_q V_q
锐钛型 Z=4, V≈136.3 Å³；金红石型 Z=2, V≈62.42 Å³；M(TiO₂)=79.87
w_a = W_a/(W_a+W_r)×100%，  w_r = 100 − w_a
```

> ⚠ **酸检数字**：因为 `(ZMV)_锐/(ZMV)_金 = (4×136.3)/(2×62.42) ≈ 4.368`，
> 若精修出来的两个 scale 恰好相等（S_a/S_r = 1），对应质量分数应是 **w_a = 81.4%**，而不是 50%。
> 这条写死成单元测试：**任何 scale→质量分数的换算错误都会在第一分钟被打出来**。
>
> ⚠ 第二大坑：合成引擎里多相叠加用的是 `w/V` 归一化并会把峰值拉到 `target_peak`、再加噪。
> 那是**合成**用的，不能直接当**精修**的前向模型。T3.2 必须写成返回**任意单位、不做归一化、不加噪**的 `compute_phase_profile()`。

## 7. 关键技术决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | **vendor 而非 import** `xrd_synth_engine` 的纯函数子集（约 250 行，保留 MIT/双许可声明），并保留一个可选 skip 的对拍测试 | 跨仓路径依赖会让 PyInstaller 打包与 CI 变脆；纯函数复制后可控可锁版本 |
| D2 | 自己写 ~60 行 LM（Levenberg–Marquardt，数值 Jacobian），**不依赖 scipy 优化器**（scipy 仍用于 `lstsq`） | 依赖越少越稳；弱模型改起来不易翻车；缺了这个 forward 无外部黑箱 |
| D3 | **变量投影（separable NLS）**：scale 与背景系数是**线性参数**，每次迭代内用 `lstsq` 解析求解；非线性层只迭代 zero / U,V,W / η / PO-r 这几个参数 | 这是让自研 Rietveld 收敛稳的关键——待优化参数从 ~15 降到 ~5，初值敏感度骤降；也是 GSAS 类软件的核心技巧 |
| D4 | Rwp 采用**含背景**的标准定义（GSAS-II 口径），并在 README 与报告中注明口径；同时输出不含背景变体便于与 FullProf 交叉 | 避免「我们的 10%」和「别人的 10%」不是一回事 |
| D5 | 背景用 **Chebyshev 多项式**（2–6 项）而非简单幂<｜hy_place▁holder▁no▁813｜>数多项式 | 高角度不易振荡发散 |
| D6 | 初值策略：**B 法初值直接吃 A 法结果**（w_a/w_r → 反推 S_a/S_r 初值） | 让方案的 A、B 两法互为支撑，也大幅降低精修跑飞概率 |
| D7 | GUI 用 PySide6 单窗口 + matplotlib 画布，与 PolyXRD 家族观感一致；核心逻辑零 GUI 依赖，CLI 与 GUI 共用 `core/` | 保证 CLI 可 CI、GUI 可换 |
| D8 | 报告导出走 **HTML → 浏览器打印 PDF**（reportlab/openpyxl 当前环境缺失，避免临时装包引入不确定性） | 与环境现状一致，减少依赖风险 |

## 8. 验证体系（这是本项目能不能"傻瓜式逐步验收"的关键）

### 三级 Round-trip（全部可在没有真实样品时进行）

| 级别 | 做法 | 判据 |
|---|---|---|
| L1 单元 | 单函数黄金值测试，含 §5 的「81.4% 酸检」、d 值与 PDF 卡片比对 | `pytest` 全绿 |
| L2 虚拟实验室 | `tools/gen_virtual.py` 以固定种子合成一批已知配比谱：0.1 / 1 / 5 / 25 / 50 / 75 / 95 / 99 %，叠加真实仪器效应（Kα 双线、择优取向、晶粒宽化、指定噪声）→ 跑通 A 法与 B 法 → 与 `truth.json` 比对 | w≥95%：\|Δ\| ≤ 0.3%abs；中低含量：\|Δ\| ≤ max(0.5%abs, 2%rel)；B 法额外 Rwp ≤ 10% |
| L3 实样交叉 | 自配 5 / 25 / 50 / 75 / 95 % 标准混合物实扫；同一份数据同时用本工具 A 法、本工具 B 法、GSAS-II（或 FullProf）算 | A/B 差 ≤ 1%abs；与 GSAS-II 差 ≤ 1.5%abs；两次平行满足重复限 |

### 让每一步都可机械验收的六条硬约束

1. **任务原子化**：每张任务卡只做一件事，新增代码 ≤ 250 行、单函数 ≤ 60 行、单文件 ≤ 400 行。
2. **契约先行**：任务卡给出函数签名、输入/输出/异常，**不允许改已有签名**（改动 = 新任务卡）。
3. **验收命令可执行**：每张卡末尾是一条能直接复制粘贴的命令，带明确数字容差。
4. **禁止顺手重构**：卡上写明「除此之外不得修改其他文件」。
5. **黄金基线守护**：`tests/golden/*.json` 存历史数值，任何漂移都被 CI 拦下。
6. **每阶段出一张图**：`tools/` 下的 demo 脚本必须产出 PNG，供人眼复核（机器过 ≠ 物理对）。

| 择优取向未被识别 | A 法偏差可达数个百分点 | A 法 QA 输出峰强比校核（对比 PDF 卡），B 法提供 March–Dollase r 精修；两者交叉报警 |
| 纳米/微晶锐钛矿宽化严重 | 峰高失真、两峰可能部分重叠 | 提供峰面积口径（可选）并在 QA 里输出 FWHM；低端含量(<0.5%)标注检出限 |
| 无定形包膜致"总量≠100%" | 客户投诉 | 报告模板固定印「结果为两晶相相对比率，不含无定形相」 |
| 恒定 m 待核条款被弄错 | 合规判定错误 | P0 专门的 T0.2 任务（原文逐字核对 + 双人复核） |
| 用单点代替多点标定，K 值不稳 | A 法结果漂移 | 强制多点（≥3）拟合并输出 R²，R² < 0.995 报警 |
