# PolyXRD RutAna 使用说明（UI 指引）

> 版本 v1.7.1 ｜ 适用：PolyXRD RutAna 桌面版（Windows EXE / 源码运行）
>
> 本文回答两个实机反馈痛点：**① 计算过程到底发生了什么（有没有在跑）**；
> **② A 法的 K 值是什么意思、怎么设、从哪里来**。

## 1. 三击完成一次测定

| 步骤 | 操作 | 界面位置 |
| --- | --- | --- |
| 1 | 「添加…」导入谱图（可多选；支持文本、RAW、MDI/GSAS、RAS、XYE/CHI、XRDML/BRML、JSON） | 左栏「导入谱图」 |
| 2 | 选 A 法或 B 法，点方法按钮 | 右栏「A 法 · 强度比值」/「B 法 · 全谱拟合」 |
| 3 | 读出结果卡，需要时「导出 HTML 报告…」 | 右栏结果卡 / 文件菜单 |

导入两份及以上谱图时，A 法会自动把第二份当作**平行样品**做双平行合并
（显示双平行差与合格判定）。

「文件 → 添加文件夹…」会扫描所选目录（不含子目录）中的全部受支持扩展名：
`.xy/.txt/.dat/.csv/.smz`、`.raw/.org/.rsm/.rbg/.rk1/.rax/.rlz/.rfi`、
`.mdi/.gsas/.gss/.gsa/.gda/.fxye`、`.ras/.rasx`、`.xye/.qye`、
`.chi/.qchi`、`.xrdml/.xml/.brml/.json`。RutAna 自己导出的结果 CSV 仍会自动
跳过，不会被误当作谱图；批量导入失败时只在最后汇总一次。RAW 按文件头自动
识别厂商变体，角度轴不可信时会提示先导出为文本格式。

## 2. 计算过程中为什么会弹窗（忙对话框）

从 v1.0.0 起，任何耗时计算都会弹出「正在计算」模态对话框，内容包括：

- **动态阶段文案**：`正在读取谱图…` → `正在测量衍射峰强度…` →
  `正在计算比率…` →（B 法）`正在 Rietveld 全谱拟合（第 12 代，Rwp=8.42%）…`；
- **百分比进度条**：算法上报进度时为确定百分比，否则自动转为**不确定模式**（来回滚动）；
- **已用时**：每秒刷新，`已用时 12 秒 / 1 分 05 秒`；
- **取消按钮**：仅当当前算法版本支持中断时才出现（不支持时对话框为**不可关闭式**，
  以避免半途关闭丢失结果）。

> **不会冻屏**：所有 core 计算都跑在后台线程（QThread），主线程只负责刷新界面。
> 若算法版本尚未上报细粒度进度，对话框会提示「当前算法版本不上报细粒度进度」，
> 仅显示阶段与已用时，属于正常的**降级表现**，不影响结果。

计算出错时忙窗自动关闭，并弹出中文错误对话框；核心模块缺失时提示
「核心算法模块尚未就绪」（保留 `CoreUnavailableError` 语义）。

## 3. A 法的 K 值到底是什么（重点）

### 3.1 一句话定义

K 是把 **最强峰净强度比** 换算成 **质量比** 的**标定曲线斜率**：
用已知配比的锐钛型/金红石型混合标准样测得强度比，再与已知质量比相除。

```
K = [ I(A) / I(R) ] ÷ [ m(A) / m(R) ]

        I(A)：锐钛型 (101) 最强峰净峰高      m(A)：锐钛型质量
        I(R)：金红石型 (110) 最强峰净峰高    m(R)：金红石型质量
```

### 3.2 结果怎么算出来

未知样品只要测得**同一对分析线**、**同样窗口**下的净强度比，代入下式即可：

```
w(A) = 1 / [ 1 + K × I(R)/I(A) ] × 100%      w(R) = 100% − w(A)
```

因此 K 直接决定结果：**K 偏大 → 锐钛型结果偏低，反之偏高**。

### 3.3 为什么不能随便填

K 与下列因素强相关，**换一台仪器或改一次条件就可能变化**：

- 波长、光路、狭缝、探测器类型、发散度；
- 取峰窗口与背景处理方式（本软件 A 法窗口可在界面上改，改了就要重新标定）；
- 制样方式（压片/涂片、粒度、取向）。

> **典型量级参考**：本项目真实数据集（同一岛津仪器条件、默认取峰窗口）
> 实测 **K ≈ 1.22**。该值仅供参考，`K=1.0` 只是软件出厂占位值，
> 不代表"无校正"，请勿直接沿用他人或文献数值。

### 3.4 得到 K 的正确姿势：内置「K 标定向导」

面板路径：**右栏 A 法 → K 值 → 🧭 K 标定向导…**

1. **准备标准混合样**：不少于 3 个已知配比的锐钛型/金红石型混合物
   （建议覆盖实际样品的含量区间，例如 w(R) = 20% / 50% / 80%）；
2. **添加谱图…**：逐个（或批量）把标样谱图加入表格；
3. **填配比（二选一）**：在「w(金红石型) / %」列填该标样的金红石型质量分数，
   或直接在「m(A)/m(R)」列填已知质量比（表格会互相反算，v1.0.0 两种录入方式都支持）；
4. **▶ 测量全部**：后台线程逐行测峰，表格回填 `I(A)/I(R)`，期间显示忙窗与进度；
5. **看曲线**：右下自动绘制标定曲线（散点 + 拟合直线）并给出 **K / 截距 / R²**，
   **R² < 0.995 会出现黄色警示**（线性不佳，建议检查配比、混样均匀性、窗口）；
6. **选口径**：默认「带截距 OLS」，也可切换「强制过原点」；
7. **采用此 K**：把 K 与 R² 回填到 A 法面板（面板会显示"当前 K 来自标定"），
   之后每次计算自动使用该 K；
8. **存档**：可「导出标定记录」为 JSON，下次「载入标定记录」直接复用。

此外，面板上的 **❓ K 值说明** 按钮可随时打开本文的定义/公式/要点摘要，
并可一键打开本文档（`docs/UI_GUIDE.md`）。

## 4. 怎么判断结果好坏

### 4.1 A 法结果卡

| 行 | 含义 | 怎么看 |
| --- | --- | --- |
| w(锐钛型) / %、w(金红石型) / % | 质量分数（2 位小数） | 主结果 |
| K | 本次计算实际使用的 K | 应与当前标定值一致 |
| I(A)/I(R) | 实测净强度比 | 数量级异常 → 检查窗口/谱图 |
| R² | 标定线性（手输 K 时为 —） | < 0.995 显示黄色警示 |
| 双平行差 / % | 两份平行样的差值 | 越小越好 |
| 判定 | 双平行差 ≤ 重复性限？ | **绿色"合格"** / 红色"超差" |
| 相对误差 / % | 勾选「与参考真值比较」后才有 | 用已知真值标样验证时用 |

> 勾选 A 法面板上的「与参考真值比较」并填入参考真值（如标准样品证书值），
> 结果卡立即给出 `(测得值 − 真值)/真值 × 100%`，便于验收型验证。

### 4.2 B 法结果卡

| 行 | 判定口径 |
| --- | --- |
| Rwp / % | **四档配色（v1.6.2）**：< 10% 绿色「拟合很好」；10–15% 蓝色「拟合良好」；15–20% 琥珀「拟合尚可」；> 20% 红色「拟合不佳」 |
| Rp / % | 参考 |
| χ² | 参考（越接近 1 越好） |
| 拟合判定 | 与 Rwp 同色一致，直接给四档文字（区间边界：10.0% 归「良好」，15.0% 与 20.0% 归「尚可」） |
| 择优取向 r（锐钛/金红石） | 精修出的 March–Dollase r（如 1.01 / 1.02）；r=1 表示无择优取向，未精修时显示「—」 |

中部画布叠加显示实测（深色）/ 计算（蓝色）/ 差值（青色），
**差值线越贴零线**，拟合越好。

结果卡下方另有「**精修结构结果**」区（v1.7.1）：每相精修后的晶胞参数、
晶胞体积与晶粒尺寸，以及承载全部附加结果的「更多信息…」窗口，见 §6。

### 4.3 B 法「精修参数」组

| 复选框 | 含义 |
| --- | --- |
| 零偏 zero | 衍射仪零点偏移 |
| 峰宽 U, V, W | Caglioti 峰宽公式参数 |
| 峰形 η | pseudo-Voigt 中 Lorentz 占比 |
| 择优取向修正（March–Dollase） | v1.4.0 新增，默认勾选：按 March–Dollase 模型精修择优取向参数 r（锐钛型默认择优面 (001)、金红石型默认 (110)，r=1 表示无择优取向）。真实数据实证默认开启不劣化 Rwp 与定量（docs/VALIDATION_v1.0.0.md §v1.4.0）；如仪器/制样确认无织构也可取消勾选 |

背景项数（真实数据 preset 固定 80 节点 tent 背景）由上层配置决定。

## 5. 主峰参数表（v1.7.0）

谱图下方的常驻表格按内置 CIF 列出**锐钛矿**与**金红石**各自最强的 5 条主峰，
导入或切换谱图后立即刷新：

| 列 | 含义 | 来源 |
| --- | --- | --- |
| 物相 | 锐钛矿 / 金红石 | 内置 CIF（COD 7206075 / 9001681） |
| 2θ / ° | 实测峰位 | 实测谱测峰，与 A 法同一 V100 背景协议 |
| d / Å | 晶面间距 | 由该行实测 2θ 经 Bragg 方程反算（λ 取谱图波长，默认 Cu Kα1 1.5406 Å） |
| (hkl) | 晶面指数 | 结构因子枚举，取该 d 上贡献最大的反射（惯例写法 101 / 110） |
| 强度 / counts | 净峰高 | 实测谱扣局部背景后的峰高；悬停显示相对强度（本相最强峰 = 100%） |
| 半峰宽 / ° | FWHM | 实测半高宽（2θ 口径） |
| 晶粒度 / nm | 谢乐晶粒尺寸 | `D = Kλ/(β·cosθ)`，K = 0.9 |

**怎么读**

- 晶粒度是**表观值**：半峰宽未扣除仪器展宽，峰越宽算出来越小，只能当下限参考；
  要得到真实晶粒尺寸，需用标准样（LaB₆ / Si）单独测仪器宽度后再扣。
- 显示「—」的行表示该峰在当前谱里**测不出**（信噪比不足，或与相邻强峰重叠）：
  重叠峰会先用 0.25° 窄窗重试，仍不行就留行提示，而不是给一个假数。
- 表格只列主峰；定量结果仍以 A 法 / B 法为准，主峰表**不参与**两法计算。

主峰区与画布之间是可拖动的分割条；无谱图时该区自动收成一行提示。

## 6. B 法精修结构结果（v1.7.1）

B 法面板的「**精修结构结果**」区，紧贴在 R 因子卡下方，显示**精修后**（而不是
CIF 原始值）的每相结构信息，一相两行：

| 行 | 含义 |
| --- | --- |
| 第一行 `a = b = …，c = …` | 精修后的晶胞参数。四方相（锐钛矿/金红石）把等长的 a、b 合成一项；等轴相只写 `a = …`；非直角晶胞在末尾补 α/β/γ |
| 第二行 `V = … Å³    D = … nm` | 晶胞体积（由六个参数重算）与该相**最强峰**的谢乐晶粒尺寸 |

**晶粒尺寸的口径**：用精修后的 Caglioti U/V/W 在该相最强峰处求半峰宽，再按
`D = Kλ/(β·cosθ)`（K = 0.9）换算。模型宽度里已含仪器展宽，因此这是**表观值
（下限）**——与谱图下方主峰参数表的口径一致，但主峰表用的是实测半高宽、
这里是精修模型宽度，两者会有几个百分点的差别，属正常。

### 6.1 「更多信息…」窗口

版面放不下的内容都在这个窗口里（点按钮弹出，模态）：

| 分区 | 内容 |
| --- | --- |
| 顶部一行 | `Rwp / Rp / χ² / λ` |
| 晶胞参数与体积 | 每相 a、b、c、α、β、γ 六个参数与 V（八列表） |
| 峰形与微结构 | 每相标度（相对）、最强峰 2θ、FWHM、晶粒 D、择优取向 r |
| 全局峰形参数与拟合统计 | λ、2θ 零点、Caglioti U/V/W、eta、不对称参数、温度因子 B、迭代次数、梯度重启、丢相序号 |

**怎么读**

- **标度**是线性最小二乘解出的相对值（各相互相耦合，绝对值无物理意义），
  只宜做跨相粗比；定量仍以结果卡里的 w(锐钛型)/w(金红石型) 为准。
- 「**梯度重启**＝是」表示本次精修中途触发过重启（LM 收敛不佳后重新起步），
  结果仍可用，但建议看一眼 Rwp 与差值线。
- 「**丢相**」列出被自动剔除的物相序号（1 起）：某相加进去后无法产生可观测
  反射（例如谱图 2θ 范围完全错过该相主峰）时会被剔除，以免拖坏整体拟合。
- 没有运行过精修时该区为一行灰字提示，按钮置灰。

## 7. 导出与报告

- **导出 HTML 报告…**：自包含单文件（嵌 PNG 图）、含样品/条件/结果/判定/标准依据；
- **导出 CSV…**：当前谱图两列数据，便于第三方处理；
- **导出 PNG…**：当前画布（含拟合叠加）图片。

报告优先导出最近一次 A 法汇总，其次 B 法。

未注册时**每次打开软件**都会弹窗：

> 本软件未注册，版权所有，禁止用于商业用途。
> 如需注册请联系 sshztx@outlook.com

| 版次 | 状态栏显示位置与样式 |

## 9. 常见疑问

| 现象 | 原因 / 处理 |
| --- | --- |
| 计算时窗口"卡住不动" | 实为模态忙窗；界面仍有动画与计时。若长期不动，看是否已用时不断刷新 |
| 只有"已用时"没有百分比 | 当前算法版本未上报细粒度进度（正常降级） |
| 结果明显偏离预期 | 先检查 K 来源是否为本次标定；再看 `I(A)/I(R)` 与差谱是否正常 |
| R² 警示 | 标定点不在一条直线上：核对配比、重新混匀、确认窗口一致 |
| 提示"核心算法模块尚未就绪" | 缺失 core 依赖或被打包裁剪，需重装完整版本 |
| 提示测峰失败 | 窗口内未找到峰或信噪比不足：调整 A/B 窗口范围或换用质量更好的谱图 |
| 每次启动都弹「未注册」提示 | 注册版未注册时的正常提示，点「确定」可正常使用；联系 sshztx@outlook.com 获取注册码（按「帮助 → 输入注册码」粘贴后不再提示） |
| 状态栏**居中**显示红色加粗的「内部评估版本」 | 这是内部评估版（单文件 exe）的版次标识，无注册机制，属正常现象 |
